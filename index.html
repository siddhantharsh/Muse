How it decides

              
Four questions, asked in the same order every time.

            

            

              When two tasks want the same hour, Muse doesn’t guess. It ranks them with a fixed
              order of questions, then fills your free time from the top of the list down.
            

          


          
    
            
  1. 
              
              
    01
    
              
    Is it at risk?
    
              
    Anything that can’t fit before its deadline — or is already late — jumps the queue.
    
            
    2. 
            
  2. 
              
              
    02
    
              
    How important?
    
              
    Your priority decides the rest: high before medium before low.
    
            
    3. 
            
  3. 
              
              
    03
    
              
    Which is due first?
    
              
    Among equals, the earlier deadline gets the earlier slot.
    
            
    4. 
            
  4. 
              
              
    04
    
              
    Which is shorter?
    
              
    Short tasks go first so the long ones can use the big gaps.
    
            
    5. 
          

          

            ALWAYS
            

              Dependencies come before all four. A task that waits on another is never
              scheduled before it — no matter how urgent it looks.
